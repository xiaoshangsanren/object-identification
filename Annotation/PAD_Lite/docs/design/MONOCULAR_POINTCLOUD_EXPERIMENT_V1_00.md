# 单目伪点云细粒度识别实验 v1.00

## 1. 数据产物

原始目标裁剪图保持不变。新增数据位于：

`datasets/processed/russian_pad_pointcloud_v1`

实际数据存放在大容量磁盘：

`/mnt/sata_ssd/cc-2025/annotation_datasets/processed/russian_pad_pointcloud_v1`

当前共转换 1,254 张图片、10 类。每张图片同时生成：

- `points_npz/<class>/<sample>.npz`：训练用定长数据；
- `points_ply/<class>/<sample>.ply`：CloudCompare/Open3D 可视化文件；
- `manifest.json`：样本类别、原图、分辨率、哈希和点云路径；
- `protocols/fivefold/`：与当前固定 Gallery 五折协议对齐的数据划分；
- `pointcloud_quality_preview_10class.png`：每类一张 RGB、深度和点云预览。

每个 NPZ 的主训练字段为：

| 字段 | 形状 | 含义 |
|---|---:|---|
| `xyz` | `[4096, 3]` | 对象中心化、95% 半径归一化的 2.5D 坐标 |
| `rgb` | `[4096, 3]` | 对应点的原始 RGB，`uint8` |
| `pixel_xy` | `[4096, 2]` | 点对应的原图像素坐标 |
| `relative_depth` | `[4096]` | 单图 2%–98% 稳健归一化相对深度 |
| `valid_mask` | `[4096]` | 低像素图片补零位置的有效性标记 |
| `dense_relative_depth` | `[H, W]` | 原分辨率稠密相对深度，供调试和重采样 |

深度由本地缓存的 Depth Anything V2 Small 产生。输入先使用边缘像素保持长宽比地填充为正方形，估深后再裁回原尺寸，避免把车辆直接拉伸成正方形。

## 2. 数据性质与结论边界

这里得到的是单目相对深度 **2.5D 伪点云**，不是 LiDAR 点云，也不是真实三维重建：

- 只有当前视角可见表面，没有车体背面；
- 没有相机内参和真实尺度；
- 每张图的深度单独归一化，不能直接跨图比较绝对距离；
- 裁剪图仍可能带有人物、地面和背景，深度模型也会同时重建这些内容；
- 60 张图片短边小于 64px，几何细节可信度更低，已在 manifest 中标记。

因此实验只能回答“单目深度形状先验能否帮助当前细粒度检索”，不能声称获得了真实车辆三维结构。

## 3. 公平对比协议

所有实验必须使用相同五折、相同固定 Gallery、相同 Query 和相同随机种子。主指标沿用当前项目的每折 Rank-1 及五折平均 Rank-1。

建议按以下顺序开展：

1. **PC0：P2B 图像基线**  
   直接复用当前最稳定的 P2B 权重和特征，作为不可变基线。

2. **PC1：XYZ-only**  
   只输入 `xyz + valid_mask`，先用轻量 PointNet++ 或 DGCNN 编码点云，输出与 P2B 相同维度的归一化检索向量。它回答“伪几何本身是否有车型判别力”。

3. **PC2：XYZ+RGB**  
   点分支输入 `xyz` 和归一化 RGB。它可测量颜色/纹理在点分支中的贡献，但不能单独证明深度有效。

4. **PC3：P2B + XYZ 晚期融合**  
   保留 P2B 图像分支，增加 XYZ-only 点分支；分别计算 Query–Gallery 相似度，再由验证集确定固定融合权重。优先采用晚期分数融合，避免小数据下联合大规模微调。

5. **PC4：P2B + XYZ+RGB 晚期融合**  
   作为可能的性能上限，但需结合负对照判断它是否仅再次利用 RGB。

## 4. 必须包含的负对照

对 PC3/PC4 至少增加：

- **Flat-Z**：所有点的 Z 设为 0，保留 XY 采样布局；
- **Shuffle-Z**：在单张图内打乱 Z，保留相同深度值分布但破坏局部几何关系；
- **RGB-grid**：保留 XY+RGB，但不给真实 Z。

只有真实 Z 的结果稳定优于 Flat-Z 和 Shuffle-Z，且在困难折上不是以其他折明显下降为代价，才能把增益归因于深度几何信息。若 PC4 提升但 PC3 和真实 Z 负对照均无提升，收益更可能来自 RGB 捷径或新增模型容量。

## 5. 低分辨率报告

主实验建议先使用短边不小于 64px 的数据；再单独报告全量 1,254 张结果。这样可以区分：

- 点云方法本身无效；
- 单目深度在极低分辨率图片上不可靠；
- 排除低分辨率样本后是否只产生选择偏差。

## 6. 判定标准

建议把“点云有帮助”定义为同时满足：

1. PC3 五折平均 Rank-1 高于 PC0；
2. PC3 高于 Flat-Z 与 Shuffle-Z；
3. Fold 2、Fold 4 至少有一折改善，且其余折没有明显系统性退化；
4. 不改变 Gallery/Query，不使用测试标签调融合权重；
5. 至少复跑 3 个种子并报告均值与标准差。

如果这些条件不成立，应保留 P2B 纯图像流程，并把伪点云判定为当前数据上的无效辅助模态，而不是继续扩大点云模型。
