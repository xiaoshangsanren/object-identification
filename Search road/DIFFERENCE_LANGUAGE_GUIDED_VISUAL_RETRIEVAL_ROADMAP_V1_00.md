# 差异语言监督的细粒度图像检索研究路线

> 版本：1.00  
> 日期：2026-09-01  
> 性质：下一阶段独立研究任务总纲  
> 适用主干：P2B以及可输出图像特征的一般视觉模型

## 0. 任务边界

这是一个从零开始的新研究任务。它只研究本文定义的训练与推理范式，所需文本数据、模型模块、训练代码、评价协议和实验结论全部独立建立。

本任务中的“差异文本”专指图像对在训练阶段配套的细粒度差异监督。

## 1. 研究问题

研究目标是把自然语言对细粒度视觉差异的表达能力，转化为视觉模型内部的判别能力：

```text
训练阶段：图像 + 类别语义 + 图像对的细粒度差异描述
测试阶段：查询图像 + Gallery图像 + 候选类别语义
```

训练时，差异文本告诉模型两幅图像在什么视觉特征上相同或不同；测试时不再提供差异文本，模型必须仅凭已经内化到视觉空间中的判别能力完成图—图检索。

需要回答的核心问题是：

> 训练期差异语言监督，能否在不依赖推理期差异文本的情况下，提高P2B或一般视觉模型对细粒度类别的图—图检索能力？

## 2. 核心假设

普通视觉检索损失只告诉模型“这两张图是否同类”，没有明确告诉模型“应该观察什么差异”。因此模型可能依赖背景、光照、纹理或拍摄条件等捷径。

本研究提出以下假设：

1. 类别语义可以定义视觉类别在语义空间中的位置；
2. 差异文本可以定义类别或样本对之间应当分离的语义方向；
3. 训练时对齐视觉差异与语言差异，可以把细粒度判别线索内化到视觉表征；
4. 将类别相关特征与图像私有干扰因素解耦，可以减少背景和成像条件造成的错误匹配；
5. 推理时无需差异文本，只需视觉特征和候选类别语义即可完成检索。

## 3. 任务形式化

### 3.1 训练样本

每个训练样本定义为：

```text
(I_q, I_g, y_q, y_g, T_q, T_g, T_diff, m)
```

其中：

- `I_q`：查询图像；
- `I_g`：训练阶段配对的Gallery图像；
- `y_q、y_g`：两幅图像的类别标签；
- `T_q、T_g`：两个类别各自的类别语义；
- `T_diff`：两幅图像所属类别之间的细粒度差异描述；
- `m=1[y_q=y_g]`：同类/异类匹配标签。

`T_diff`只存在于训练数据流中。

### 3.2 测试输入

测试阶段输入：

```text
Query图像 I_q
Gallery = {(I_gi, c_i)}
候选类别语义 = {T_ci}
```

测试阶段不存在`T_diff`，也不动态生成或检索差异描述。

### 3.3 输出

模型输出每个Query对应的Gallery排序：

```text
rank(I_q) = [I_g(1), I_g(2), ..., I_g(N)]
```

Rank-1位置对应最终预测类别。

## 4. 总体模型结构

```text
                         ┌─────────────────────────────┐
Query/Gallery图像 ──────→│ 视觉主干：P2B或一般视觉模型 │
                         └──────────────┬──────────────┘
                                        │ z_img
                           ┌────────────┴────────────┐
                           │                         │
                    类别相关分支                 图像私有分支
                      E_hom                       E_het
                           │                         │
             用于检索、类别语义对齐          只用于训练期解耦

类别语义 T_c ─────→ 冻结文本编码器 ─────→ E_c
差异文本 T_diff ──→ 冻结文本编码器 ─────→ E_diff（仅训练）
```

其中：

- `E_hom`：与类别判断和图像匹配有关的共享判别特征；
- `E_het`：与单张图像有关、但不应该主导类别匹配的私有特征，例如背景、光照、噪声和成像风格；
- `E_c`：候选类别语义特征；
- `E_diff`：训练期差异语言特征。

## 5. P2B上的实现

### 5.1 P2B保持原有职责

P2B继续负责从视觉主干中获得：

- 全局CLS特征；
- Patch局部特征；
- Patch评分与Top-K聚合；
- 全局—局部融合后的检索特征`z_p2b`。

第一版不修改P2B内部的Patch选择规则。新方法接在`z_p2b`之后，以便先验证差异语言监督本身是否有效。

### 5.2 新增轻量解耦头

```text
E_hom = normalize(H_hom(z_p2b))
E_het = normalize(H_het(z_p2b))
```

`H_hom`和`H_het`是两个独立的轻量投影头。

第一阶段只训练新增模块，冻结P2B视觉主干；确认方法有效后，再考虑解冻视觉主干最后若干层。

## 6. 一般视觉模型上的实现

对于DINOv2、ViT、ConvNeXt等模型，先统一其输出接口：

```text
z_img = VisualEncoder(I)
```

- 如果模型输出CLS Token，直接作为全局特征；
- 如果模型输出二维特征图，使用全局平均池化获得全局特征；
- 如果模型同时输出Patch/空间特征，可额外接入P2B式Patch聚合，但不是第一版的必要条件。

之后使用与P2B相同的`H_hom/H_het`、文本编码器和损失函数，从而保证方法可以跨视觉主干比较。

## 7. 文本监督数据

### 7.1 类别语义

每个类别准备若干条独立语义描述`T_c`，内容描述该类别本身可观察的外观特点。

类别语义满足：

- 训练和测试都允许使用；
- 每个候选类别使用同样数量和模板层级的描述；
- 不包含训练集文件名、背景来源或数据集名称；
- 多条描述编码后取平均，形成稳定的类别语义原型。

### 7.2 差异文本

为训练类别对准备`T_diff(a,b)`，描述类别`a`与类别`b`在可观察视觉结构上的相同点和差异点。

差异文本满足：

- 只用于训练；
- 必须绑定有顺序的类别对`a → b`；
- 描述视觉可见差异，不写背景、拍摄地点或数据来源；
- 不直接输入“哪一个类别是正确答案”之类的结论句；
- 同一类别对准备多种等价表述，降低对固定句式的记忆；
- 反向文本`T_diff(b,a)`必须同步交换比较方向。

### 7.3 正样本的差异描述

当`y_q=y_g`时，`T_diff`描述同类图像在视角、尺度、遮挡和成像条件变化下仍保持一致的类别结构，不强行制造不存在的类别差异。

### 7.4 数据泄漏限制

- 测试Query不得出现在训练图像对中；
- 测试图像的人工观察结果不得写回训练差异文本；
- 文本不得包含图像文件名或唯一实例信息；
- 数据划分先完成，再构建训练样本对；
- 差异文本的生成记录、版本和适用类别对必须可追踪。

## 8. 训练目标

总体损失定义为：

```text
L_total =
    L_match
  + λ_task · L_task
  + λ_sem  · L_sem
  + λ_diff · L_diff
  + λ_dec  · L_decouple
```

### 8.1 主匹配损失 `L_match`

使用图像对的同类/异类标签监督`E_hom`：

```text
s_qg = cosine(E_hom_q, E_hom_g)
L_match = BinaryMatchingLoss(s_qg, m)
```

它直接学习两幅图像是否应该匹配。

### 8.2 图像检索任务损失 `L_task`

保留原视觉模型的检索训练目标，例如：

```text
L_task = L_ID + L_Triplet
```

如果P2B当前实验还使用SupCon，则把SupCon作为`L_task`的可配置组成部分，而不是删除原实现。

### 8.3 类别语义对齐损失 `L_sem`

将类别相关视觉特征与正确类别语义对齐，并与其他候选类别拉开：

```text
L_sem = InfoNCE(E_hom, E_c, label=y)
```

该分支在训练和测试阶段都具有对应输入。

### 8.4 差异文本辅助损失 `L_diff`

先由图像对构建视觉关系向量：

```text
R_v = RelationHead(
        E_hom_q,
        E_hom_g,
        E_hom_q - E_hom_g,
        |E_hom_q - E_hom_g|,
        E_hom_q ⊙ E_hom_g
      )
```

将`R_v`与差异文本特征`E_diff`对齐：

```text
L_diff = 1 - cosine(R_v, E_diff)
```

同时在一个batch内加入错误类别对文本作为负样本，避免所有关系向量坍缩到同一方向。

这个损失只在训练阶段计算。推理模型不接收`T_diff`。

### 8.5 解耦损失 `L_decouple`

约束类别相关特征与图像私有特征分离：

```text
L_ortho = ||E_hom^T E_het||²
L_decouple = L_ortho + λ_cov · L_cross_cov
```

如果后续证明需要更强的分布约束，再把MMD作为可选实验加入；第一版不同时堆叠过多正则项。

## 9. 训练流程

```text
1. 固定训练/验证/测试划分
2. 为训练类别建立类别语义和有方向的类别对差异文本
3. 从训练集采样Query—Gallery正负图像对
4. 图像经过P2B或一般视觉模型获得z_img
5. 解耦头产生E_hom和E_het
6. 冻结文本编码器产生E_c和E_diff
7. 计算匹配、检索、类别语义、差异文本和解耦损失
8. 反向传播只更新当前实验允许训练的视觉模块
9. 使用验证集选择超参数和最佳检查点
10. 测试时彻底关闭差异文本数据流
```

### 9.1 两阶段优化

第一阶段：

- 冻结视觉主干；
- 训练解耦头、关系头和必要的投影层；
- 验证新增监督是否具有独立价值。

第二阶段：

- 使用第一阶段最优配置；
- 逐步解冻视觉主干最后`N`层；
- 使用更小学习率更新主干；
- 观察收益是否来自视觉表征真正改变，而不只是新增头的容量。

## 10. 测试流程

```text
Query图像 ──→ 视觉编码器 ──→ E_hom_q

Gallery图像 ──→ 视觉编码器 ──→ E_hom_gi
候选类别语义T_ci ──→ 文本编码器 ──→ E_ci

score(q, gi)
  = α · cosine(E_hom_q, E_hom_gi)
  + β · cosine(E_hom_q, E_ci)

按score从高到低排列Gallery
```

测试阶段：

- 不读取`T_diff`；
- 不构造图像对差异文本；
- 不运行关系头；
- 不使用`E_het`参与最终匹配；
- 最终排序只采用本节定义的图—图与图—类别语义分数。

`α、β`只能在验证集上确定，不能根据测试集结果调节。

## 11. 研究阶段

### S0：建立独立基线

目标：冻结当前代码状态和实验协议。

工作：

- 用P2B原始流程获得基线结果；
- 固定数据划分、Gallery和评价脚本；
- 保存逐样本相似度、排序和类别结果；
- 确认后续实验只改变规定变量。

输出：可重复的P2B视觉检索基线。

### S1：建立新任务的文本数据

目标：只为本研究建立类别语义和训练期差异描述。

工作：

- 定义全新的JSON Schema；
- 编写类别语义；
- 编写有方向的类别对差异文本；
- 进行格式、方向一致性和数据泄漏检查；
- 生成训练图像对索引。

输出：独立、可版本化的训练文本监督数据。

### S2：视觉解耦与类别语义对齐

目标：先实现不含差异文本的结构基线。

工作：

- 在P2B输出后加入`H_hom/H_het`；
- 加入类别语义编码和`L_sem`；
- 加入`L_decouple`；
- 冻结视觉主干训练新增模块。

输出：能够在测试阶段执行图—图和图—类别语义联合匹配的模型。

### S3：加入训练期差异语言监督

目标：验证截图方法的核心假设。

工作：

- 实现图像对关系头；
- 编码`T_diff`；
- 加入`L_diff`和batch内负差异文本；
- 保证测试入口无法接收`T_diff`；
- 与S2使用完全相同的数据划分和训练预算。

输出：训练使用差异文本、测试不使用差异文本的完整模型。

### S4：视觉主干微调

目标：让差异监督真正改变视觉表征。

工作：

- 从只训练新增头开始；
- 依次解冻主干最后1、2、4层；
- 分别设置主干学习率与新增模块学习率；
- 选择收益与训练成本平衡最好的配置。

输出：P2B上的最优训练策略。

### S5：迁移到一般视觉模型

目标：判断方法是否独立于P2B。

工作：

- 选择至少一个不含P2B Patch聚合的视觉模型；
- 使用相同文本、划分、损失和训练预算；
- 比较绝对结果与相对提升；
- 判断差异监督是通用方法还是只适合P2B。

输出：一般视觉模型上的复现实验。

## 12. 必做消融实验

| 编号 | 视觉模型 | 新增解耦头 | 类别语义 | 差异文本 | 目的 |
|---|---|---:|---:|---:|---|
| A0 | P2B | 否 | 否 | 否 | 原始视觉基线 |
| A1 | P2B | 是 | 否 | 否 | 排除新增参数量带来的提升 |
| A2 | P2B | 是 | 是 | 否 | 测量类别语义的作用 |
| A3 | P2B | 是 | 是 | 是 | 完整方法 |
| A4 | P2B | 是 | 是 | 随机打乱 | 判断文本内容是否真正有效 |
| A5 | P2B | 是 | 是 | 交换方向 | 判断模型是否理解差异方向 |
| A6 | P2B | 是 | 是 | 是，测试时移除 | 验证正式推理协议 |
| A7 | 一般视觉模型 | 是 | 是 | 是 | 验证方法通用性 |

A3、A4、A5必须使用相同参数量和训练预算。只有A3显著优于A4/A5，才能说明收益来自正确差异语义，而不是文本正则化或额外训练步骤。

## 13. 评价指标

### 13.1 主指标

- Micro Rank-1；
- Macro Rank-1；
- 每类别Rank-1。

### 13.2 检索辅助指标

- Recall@5；
- mAP；
- 正确类别与最强错误类别之间的相似度间隔；
- 每张Query平均推理耗时。

### 13.3 诊断指标

- 图—正确类别语义相似度；
- 正确差异文本对齐准确率；
- 随机文本负对照结果；
- 交换方向负对照结果；
- `E_hom/E_het`交叉协方差；
- 相对A0被纠正和被破坏的样本数量。

诊断指标只用于解释训练机制，不替代Rank-1作为主要结论。

## 14. 成功判据

完整方法需要同时满足：

1. A3在测试集Rank-1上优于A0、A1和A2；
2. A3优于随机文本A4和交换方向A5；
3. 测试时完全不提供`T_diff`，结果仍然成立；
4. 提升不是由少数大类样本主导，Macro和逐类结果同步检查；
5. 原本表现较好的类别没有出现不可接受的大幅退化；
6. 至少在P2B和一种一般视觉模型上验证方法的可迁移性。

如果A3与A4/A5没有显著差异，则不能声称模型利用了差异语言语义。

## 15. 停止与回退条件

- 如果A1就能获得与A3相同提升，优先判定为模型容量效应；
- 如果A3和随机文本A4相同，停止扩大文本规模，先检查对齐损失；
- 如果训练对齐指标上升但测试Rank-1下降，降低`λ_diff`并检查任务冲突；
- 如果`E_hom/E_het`未发生有效分离，先简化解耦目标，不继续堆叠正则项；
- 如果冻结主干无效但解冻后有效，说明训练监督必须进入视觉表征；
- 如果P2B有效而一般视觉模型无效，需要把结论限定为P2B适配方法。

所有新实现建立独立命名空间，不与其他研究分支共享文本数据流或实验配置。

建议结构：

```text
Annotation/PAD_Lite/src/diff_language_retrieval/
├── schemas.py
├── pair_dataset.py
├── text_encoder.py
├── disentangle_head.py
├── relation_head.py
├── losses.py

Annotation/PAD_Lite/configs/diff_language_retrieval/
├── p2b_baseline.yaml
├── p2b_semantic.yaml
├── p2b_full.yaml
└── generic_visual_full.yaml
```

实现要求：

- 不覆盖P2B原有实验入口；
- A0～A7通过配置切换；
- 训练和测试Dataset类分离；
- 测试Dataset与模型前向接口中不存在`T_diff`字段；
- 所有文本缓存带版本号和文本编码器标识；
- 检查点记录损失权重、主干解冻层数和文本数据版本。

5. A0～A7实验结果；
6. 随机文本和交换方向负对照结果；
7. Rank-1、逐类结果、检索指标和推理耗时；
8. 对“差异语言是否真正被视觉模型内化”的结论。

## 19. 一句话总路线

> 用全新构建的细粒度差异语言在训练阶段监督图像对关系，并把类别判别特征与图像私有干扰因素解耦；测试阶段彻底移除差异文本，只用Query图像、Gallery图像和候选类别语义完成细粒度图—图检索。
